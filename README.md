## Entry

> WARNING: this human will say 'one more episode' and mean four.

## How it works

`main.ts` deterministically writes the single-line entry above to `/output/entry.txt` (creating `/output` if needed), with no randomness, no network access, and no input. It then re-reads the file and verifies it is exactly the entry line: 62 code points, one line, within the 160-character limit.
